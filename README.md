# SwirX's ComputerCraft Projects
Hey! These are a bunch of scripts and projects I made about 3 years ago for the **CC:Tweaked** mod in Minecraft. Most of them explore custom network protocols, UI, and hardware manipulation using Lua. You can find detailed development info inside each folder.

## The Projects

* [**SX-UI**](./SX-UI): A massive, fully object-oriented GUI library to make building buttons, labels, and textboxes super easy on CC terminals.
* [**SX-Chat**](./SX-Chat): A simple client/server Rednet chat application. Includes a secure server-side login feature that hides passwords from wandering eyes.
* [**SX-Crypt**](./SX-Crypt): Native Lua implementations of hashing algorithms (MD5, SHA3, MORUS). Useful for encrypting data or sending secure Rednet messages.
* [**SX-Doors**](./SX-Doors): A remote Redstone door controller. The backend listens over a Rednet port to securely pulse doors open.
* [**SX-FTP**](./SX-FTP): A file transfer protocol script. Sends files securely across modems with host-client dynamics, kicking mechanics, and dynamic file handling.
* [**SX-Installer**](./SX-Installer): A visual OS installer that fetches libraries from an external web server and walks you through standard/custom installation setups.
* [**SX-Mine**](./SX-Mine): An intelligent turtle script that actively inspects its surroundings to hunt specifically for valuable ores like diamonds and emeralds, digging out entire veins recursively.
* [**SX-Music**](./SX-Music): A combination of a Python backend and Lua scripts that downloads actual music/videos and converts them to DFPWM to play natively out of CC speakers. 
* [**parser**](./parser): A native HTML parser in Lua. Lets computers scrape HTML tags off sites fetched via the HTTP API.
* [**SX-Store**](./SX-Store): A tiny proof of concept showcasing how to construct a multi-button interactive program using the UI library.
* [**SX-Viewer**](./SX-Viewer): A visual file viewer script acting as a read-only graphical explorer.

*(There is also a standalone script, `car.lua`, which is a quick calculator script I wrote for determining displacement volume and IMEP for engines!)*
