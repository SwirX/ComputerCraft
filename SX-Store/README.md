# SX-Store

A very simple example of how to make an interface using uiV2.

### Implementation details
This was basically just me testing out my custom UI library (`uiV2`). The `store.lua` script creates two buttons on the screen with distinct colors, and a text label underneath them. When either button is clicked, the text label updates to show which one was pressed.

### Development status
It works perfectly as a proof of concept for the UI system, but there isn't any actual "store" functionality yet like buying or downloading software. It's just testing the button callbacks and screen rendering loop.
